# Installation
This theme can be installed two ways to your Omarchy system. Choose one.

### TERMINAL
`omarchy-theme-install https://github.com/JJDizz1L/neon-easter.git`
### OMARCHY LAUNCHER MENU
1. Copy this link: `https://github.com/JJDizz1L/neon-easter.git`
2. Open Omarchy launcher, `SUPER+ALT+SPACE`, navigate to: Install < Style < Theme
3. Paste: `CTRL+SHIFT+V`, then press enter/return.

### EXTRA
Omarchy Themes can be enhanced your theming such as customizing: neovim, shaders, fonts, templates, generating colors, GTK app colors (experimental), and more!
1. Using Aether App, pre-installed on Omarchy Hyprland Systems.
2. If you're not using Omarchy or uninstalled default applications, you can install Aether from the AUR:</br> `yay -S aether`
  - https://github.com/bjarneo/aether

In addition to Aether, you can go even further by exploring `omarchy-theme-hook`, which allows for further customization to your system. 
This allows for automatically theming: Alacritty, Cava, Chromium, Cursor, Discord, Firefox, Ghostty, GTK, Hyprland, Kitty, Mako, QT6, Spotify, Steam, Superfile, SwayOSD, Vicinae, VS Code, Walker, Waybar, Windsurf, Zed, and Zen Browser.
  - https://github.com/OldJobobo/theme-hook-plugin-manager

### System Modifications
Neon Easter customizes your system with dark backgrounds and adds bright vibrant colors. If you have an OLED display; Neon Easter excells.</br>
- Supported Terminals: Alacritty, Kitty, Ghostty, Foot.
- Supported Browsers: Chromium, Brave, Brave Origin,Helium Browser, Google Chrome, Microsoft Edge.
- Modifies TUI colors: nvim/lazyvim, btop++, nvtop, etc.
- Omarchy Quickshell: Stays default, color change only.
- Omarchy App launcher: Stays default, color change only.
- Omarchy Hyprland Lockscreen: Stays default, color change only.
- Adds seven 4K wallpapers.
- Added Discord (System24) Theme CSS file in root folder.</br>
(Note: Steps below not needed with omarchy-theme-hook installed.)
  - Equicord/Vencord/Vesktop is required to alter your Discord theme.
  - For Equicord/Vencord/Vesktop, follow these steps:
    - Copy ~/.config/omarchy/themes/neon-easter/vencord.theme.css to ~/.config/Equicord/themes/.
    - Copy ~/.config/omarchy/themes/neon-easter/vencord.theme.css to ~/.config/Vencord/themes/.
    - Copy ~/.config/omarchy/themes/neon-easter/vencord.theme.css to ~/.config/Vesktop/themes/.
  - Open Discord, Navigate to Settings > Themes.
  - Click, "Load missing Themes", Tick "Omarchy System24".
